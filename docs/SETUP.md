# Setup guide (phone only, no computer needed)

All of this works from the GitHub app or the browser on an Android phone.
Nothing needs to be installed on your phone. The heavy work (3D rendering,
voices, FFmpeg) runs on free GitHub cloud computers.

## Step 1: Put the code on the `main` branch

GitHub only shows the "Run workflow" button for workflows that live on the
default branch (`main`). That means the development branch has to be merged first:

1. Open the repository on GitHub and tap **Pull requests**.
2. Open the pull request for `claude/animated-shorts-studio-rtev6p` and tap **Merge**.
   (If there isn't one yet, ask Claude to create it.)

## Step 2: Turn on the dashboard website (GitHub Pages)

1. Repository → **Settings** → **Pages**.
2. Under **Build and deployment → Source**, choose **GitHub Actions**.
3. Go to the **Actions** tab, open **Deploy dashboard**, and tap **Run workflow**.
4. Wait for the green tick (about 1 minute). The dashboard is now at
   `https://thomas7277262-bit.github.io/animated-shorts-studio/`.
   Add it to your home screen from the browser menu (⋮ → *Add to Home screen*).

## Step 3: Make a token so the dashboard can start renders

The token is a password that only allows starting renders in this one repository.
It is stored only in your phone's browser.

1. GitHub → your profile picture → **Settings** → **Developer settings** →
   **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
2. Name: `shorts-studio`. Expiration: whatever you like (for example 90 days).
3. **Repository access → Only select repositories →** `animated-shorts-studio`.
4. **Permissions → Repository permissions:**
   - **Actions: Read and write** (to start renders)
   - **Contents: Read-only**
5. Tap **Generate token** and copy it.
6. In the dashboard, step 6 *Render video* → *GitHub connection*: paste the token.

## Step 4: Make a video

1. Type an idea (or leave it empty) and pick a length.
2. Optional: pick up to 3 characters, then tap **Generate story**.
3. Edit any line of the script if you like.
4. Pick a narrator voice and music. Use **Preview** to watch the scenes.
5. Pick a resolution and tap **Render video in the cloud**.
6. Wait. Rough times on GitHub's free computers for a 15 s video:
   1080p ≈ 3–5 min, 4K ≈ 12–15 min. 60 s at 4K 60 fps can take over an hour.
7. When it says **Finished**, tap **Download MP4**. Every finished video also stays
   under **Finished videos** and in the repository's **Releases** page.

## Without the dashboard

Actions tab → **Render video** → **Run workflow**. Tick **demo** or type an idea,
then choose a resolution. When it finishes, the MP4 is on the **Releases** page.
